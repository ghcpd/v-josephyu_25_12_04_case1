# DEFECTS FOUND IN README vs IMPLEMENTATION

## DEFECT 1: CLI Arguments Not Supported
**Title:** Flask app ignores --host and --port command line arguments
**Description:** README documents running the app with `python app.py --host=0.0.0.0 --port=8080`, but Flask's app.run() does not parse these arguments. The server starts on default 127.0.0.1:5000 instead.
**Reproduction Steps:**
  1. Run: `python app.py --host=0.0.0.0 --port=8080`
  2. Expected: Server runs on 0.0.0.0:8080
  3. Actual: Server runs on 127.0.0.1:5000
**Error Trace:** 
  * Running on http://127.0.0.1:5000
**Root Cause:** app.run(debug=True) uses default values. To accept CLI arguments, need Flask.cli or argparse.
